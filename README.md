# GrimReich

GrimReich 1.0 — mobilna gra RPG na Androida osadzona w mrocznym świecie Grimreich.

## Opis

GrimReich to mobilna gra RPG, w której gracz wciela się w bohatera przemierzającego krainę GrimReich. Gra rozwija system postaci, reputacji, religii, walki i zakończeń bez odniesień do starego brandingu.
